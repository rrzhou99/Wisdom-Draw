# Wisdom-Draw: AI-Generated Bilingual Web Application

## Overview
Wisdom-Draw is an interactive, bilingual (English and Chinese) web application that utilizes dynamic user-input logic and randomized text generation (a 1–70 draw function). 

More importantly, this project serves as a practical demonstration of **AI-assisted software development and technical product ownership**. The entire frontend architecture, logic, and localization were generated by an LLM (Gemini) through rigorous prompt engineering and technical specification design.

## Key Features

*   **Dynamic Generation Logic:** Implements a randomized 1–70 draw function that processes user input and dynamically renders specific, localized text outputs.
*   **Bilingual Localization:** Fully supports dual-language toggling (English/Chinese), maintaining strict UI consistency and accurate cultural translation across both states.
*   **Responsive UI/UX:** Features a clean, accessible, and responsive interface built with modern web standards.
*   **Serverless Deployment:** Hosted entirely on GitHub Pages for high availability and zero-maintenance continuous deployment.

## Development Methodology: Agentic AI Workflow

This project was built to test the capabilities of LLMs in accelerating the Software Development Lifecycle (SDLC). Instead of writing raw syntax, my role was equivalent to a **Technical Program Manager / Product Owner**:

1.  **Requirements Definition:** Defined the core user journey, logic constraints, and localization requirements.
2.  **Prompt Engineering (Specification):** Translated these complex requirements into crisp, actionable technical prompts that the LLM could execute without hallucination or logic errors.
3.  **Iterative QA & Refinement:** Conducted User Acceptance Testing (UAT) on the AI-generated code, troubleshooting logic bugs and refining the prompts to patch UI and algorithmic issues.

## Tech Stack
